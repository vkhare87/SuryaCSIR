# T5 — Ask SURYA Implementation Plan

> REQUIRED SUB-SKILL for agentic execution: superpowers:subagent-driven-development or executing-plans.

**Goal:** Role-scoped NL query surface — `/query` on the RAG service (router → document traversal | whitelisted analytics) + a SPA `/ask` page, with citations.

**Architecture:** Caller's Supabase JWT used end-to-end so RLS is the only doc-scoping gate. Pure router/retrieval/analytics/answer modules (fake-tested); thin `auth.py`/`api.py` (FastAPI) reviewed only.

## Global Constraints
- No service key in the query path — user-scoped Supabase client only.
- Structured path executes only names in the `ANALYTICS` whitelist; never free-form SQL.
- Router returns exactly `'document'` or `'structured'` (no hybrid); default `'document'`.
- SPA: `VITE_RAG_URL` env; semantic tokens; `import type`; page default export, lib named export.

---

### Task 1: `answer.py` — shared shapes
- Create `rag/answer.py`, test `rag/tests/test_answer.py`.
- Produces `@dataclass Citation(document_id, title, node_title, page_start, page_end)` and
  `@dataclass Answer(text: str, mode: str, citations: list)`.
- Test: construct an `Answer` with one `Citation`; assert fields. Commit.

### Task 2: `router.py`
- Create `rag/router.py`, test `rag/tests/test_router.py`.
- `route(question: str, llm) -> str`: prompt llm to classify; read llm reply; return
  `'structured'` iff reply lowercased contains `structured`, else `'document'`.
- Interfaces: consumes an llm with `.classify(question) -> str` (add to adapters) OR reuse
  `.summarize`; to keep the llm adapter small, define `route` to call `llm.classify` and add
  `classify` to `FakeLLM`/`OpenLLMClient` in this task.
  - `FakeLLM.classify(q)` returns `"structured"` if `q` startswith `"COUNT"` (deterministic
    test hook) else `"document"`.
  - `OpenLLMClient.classify(q)` posts a classification prompt, returns raw content.
- Tests: `route("COUNT things", FakeLLM()) == 'structured'`; `route("what is X", FakeLLM())
  == 'document'`. Commit.

### Task 3: `retrieval.py`
- Create `rag/retrieval.py`, test `rag/tests/test_retrieval.py`.
- `traverse(docs, question, llm) -> Answer`, `docs = [{"id","title","tree"}]`:
  - flatten `tree["root"]["nodes"]` → candidates `[(doc_id, doc_title, node)]`.
  - `picks = llm.pick(question, [node["title"] for ...])` → list[int] indices.
  - context = "\n".join picked node summaries; `text = llm.summarize(context)`.
  - citations = `Citation(doc_id, doc_title, node["title"], node["page_start"], node["page_end"])`
    for each pick. Empty candidates → `Answer("No documents available to answer this.",
    "document", [])`.
- Add `FakeLLM.pick(q, titles) -> [0]` (deterministic). `OpenLLMClient.pick` posts a prompt
  asking for indices, parses ints from the reply.
- Tests: 2 docs each 1-node tree, FakeLLM picks [0] → `len(citations)==1`, citation
  `document_id` == first doc id, `page_start`==1; empty docs → `citations==[]`. Commit.

### Task 4: `analytics.py`
- Create `rag/analytics.py`, test `rag/tests/test_analytics.py`.
- `ANALYTICS = {"count_documents_by_status": _count_documents_by_status}`.
  `_count_documents_by_status(params, client) -> Answer`: uses `client` to count documents
  grouped by `ingest_status` (via a simple select) → structured Answer text, `citations=[]`.
- `run_analytics(name, params, client)`: `fn = ANALYTICS.get(name); if not fn: raise
  ValueError(...); return fn(params, client)`.
- Tests (fake client with a `.table().select().execute()` stub, or inject a fake fn):
  `run_analytics("bogus", {}, None)` raises `ValueError`; a whitelisted name dispatches to its
  fn (register a probe fn in the test via monkeypatch, or assert the real one returns an Answer
  with `mode=="structured"` using a stub client returning 3 rows). Commit.

### Task 5: `auth.py` (thin, reviewed)
- Create `rag/auth.py`.
- `verify_token(jwt, anon_url, anon_key) -> user`: build anon client, `client.auth.get_user(
  jwt)`; raise `PermissionError` on failure. `scoped_client(anon_url, anon_key, jwt) -> Client`:
  anon client with the JWT set as the postgrest auth header so RLS applies.
- No unit test (needs live Supabase). Docstring notes the security contract. Commit.

### Task 6: `api.py` (FastAPI, thin, reviewed)
- Create `rag/api.py`; add `fastapi`, `uvicorn`, `httpx` to `rag/requirements.txt`.
- `POST /query {question}` + `Authorization: Bearer`. Extract jwt → `verify_token` (401 on
  fail) → empty question 400 → `scoped_client` → `route` → document: select readable
  `doc_indexes` joined `documents` (id,title,tree) via scoped client, `traverse`; structured:
  llm proposes `{function, params}`, validate ∈ ANALYTICS else document fallback,
  `run_analytics`. Serialize Answer (dataclasses.asdict) to JSON.
- Config: reads `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `OPENLLM_*`, `LLM_BACKEND` from env
  (extend `config.py` with `supabase_anon_key`; keep service key optional for the worker).
- No local run test (native/framework + live services). README: `uvicorn api:app`. Commit.
